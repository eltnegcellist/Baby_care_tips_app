## GitHub Pages

このリポジトリはビルド不要の静的サイトです。

GitHub の **Settings → Pages** で次のように設定すれば公開できます。

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

保存後、Pages の公開URLが生成されます。

## Structure

- `index.html` — 記事一覧
- `episode01.html` 〜 `episode08.html` — 各記事
- `style.css` — 共通スタイル
- `.nojekyll` — GitHub PagesでJekyll処理を避けるための空ファイル

## Notes

各記事の参考文献は公開済み論文・ガイドラインを記載しています。個別の医療上の指示がある場合は、それを優先してください。
